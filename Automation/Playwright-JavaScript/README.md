# Playwright JavaScript Automation

## Overview

This project contains UI automation test scripts developed using Playwright with JavaScript.

## Tools & Technologies

- Playwright
- JavaScript
- Node.js
- Git & GitHub

## Testing Areas

- Login functionality
- Positive and negative test scenarios
- UI validation
- Assertions
- Cross-browser testing
- Automated test reporting

## Framework

The project follows a structured automation approach using:

- Page Object Model (POM)
- Playwright Test
- Reusable locators
- Assertions
- Configuration management
